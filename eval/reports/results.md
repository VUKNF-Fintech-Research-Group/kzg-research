Cause, both: the reference fixtures used small integer IDs (S1: even integers 2, 4, ...; S2: z = 10d + 7), whose calldata has many zero bytes. Reproduced 2026-11-13: S1 with the old IDs at depth 12 gives 38,300-38,330 gas (153 of 548 calldata bytes zero). In both runs S1 sits on the EIP-7623 floor, where each zero byte that becomes non-zero adds 30 gas: +2,730 is about 91 bytes. S2 is below the floor, so each such byte adds 12 gas: z's 31 zero bytes explain about +370. Handles here are uniform 255-bit values as the plan requires. Not a bug: the reference values understate cost for realistic handles
